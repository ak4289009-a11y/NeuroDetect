HOW TO RUN THE APPLICATION ON ANY COMPUTER:
-------------------------------------------

PREREQUISITES:
  - Python 3.10+ (Check "Add Python to PATH" during installation)
  - Node.js is NOT required for running (React frontend is pre-compiled)


OPTION 1: ONE-CLICK LAUNCHER (RECOMMENDED FOR WINDOWS)
------------------------------------------------------
  Double-click "START_NEURODETECT.bat" in this directory.
  - Automatically creates Python virtual environment if missing.
  - Automatically installs dependencies from requirements.txt on first run.
  - Automatically seeds the database with test accounts and sample cases.
  - Starts the backend server and opens http://127.0.0.1:8000 in your browser.


OPTION 2: COMMAND LINE (WINDOWS / MACOS / LINUX)
------------------------------------------------
1. Open terminal and navigate to backend:
   cd BrainTumer/backend

2. Create & activate virtual environment:
   # Windows PowerShell:
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   (Note: If execution policy blocks it, run: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass)

   # Windows Command Prompt (CMD):
   python -m venv venv
   venv\Scripts\activate.bat

   # macOS / Linux:
   python3 -m venv venv
   source venv/bin/activate

3. Install dependencies:
   pip install -r requirements.txt

4. Initialize database:
   python seed_data.py

5. Run server:
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

6. Open browser:
   http://127.0.0.1:8000


OPTION 3: VS CODE ONE-CLICK RUN
-------------------------------
1. Open the "BrainTumer" folder in VS Code.
2. Select Python Interpreter: Ctrl+Shift+P -> "Python: Select Interpreter" -> .\backend\venv\Scripts\python.exe
3. Press Ctrl + Shift + B -> Select "Run Backend Server (Port 8000)".
4. Or press F5 to launch with debugger.
